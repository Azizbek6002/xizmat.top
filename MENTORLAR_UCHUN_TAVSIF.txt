UMUMIY ARXITEKTURA
──────────────────
Loyiha klassik "Full Stack Web Application" arxitekturasida qurilgan:

  Frontend  →  React.js (SPA)
  Backend   →  Node.js + Express.js (REST API)
  Database  →  SQLite (better-sqlite3)
  Deploy    →  Lokal yoki istalgan VPS (Node.js ishlasa yetarli)

Alohida "processing-service" (Python) — kelajakdagi 3D/VR qayta ishlash uchun.


─────────────────────────────────────────
1.1 FRONTEND — React.js
─────────────────────────────────────────

Nima uchun React?
  React — hozirgi kunda eng keng tarqalgan UI kutubxonasi. Komponentlar
  asosidagi tuzilma kodni qayta ishlatishga imkon beradi. Virtual DOM
  orqali faqat o'zgargan qismlar yangilanadi — bu tezlikni oshiradi.

Ishlatilgan asosiy texnologiyalar:

  React Router (react-router-dom v6)
    Sahifalar o'rtasida navigatsiya. PrivateRoute komponenti orqali
    foydalanuvchi rolini tekshirish (user / owner / admin).
    Misol: /dashboard faqat owner yoki admin roli bo'lsa ochiladi.

  Context API (React built-in)
    Global state boshqaruvi uchun:
    - AuthContext  → foydalanuvchi ma'lumotlari, login/logout
    - LanguageContext → til tanlash (uz/ru/en), t() funksiyasi orqali
      barcha textlar tarjima qilinadi

  Axios (api.js)
    HTTP so'rovlar uchun. Request interceptor — har bir so'rovga
    avtomatik JWT token qo'shadi. Response interceptor — 401 xatoda
    tokenni o'chirib /login ga yo'naltiradi.

  Leaflet + react-leaflet
    OpenStreetMap asosida interaktiv xarita. Foydalanuvchi joylashuvini
    aniqlash (Geolocation API), eng yaqin bizneslarni ko'rsatish,
    OSRM marshrutizatsiya (yo'nalish qurish).

  Three.js (VirtualTourModal.js)
    3D/VR ko'rish uchun. Biznes xona videosini immersive (360-darajali
    effekt) formatda ko'rsatadi. Sichqoncha bilan boshqarish, klaviatura
    navigatsiyasi.

  i18n (o'z yechimimiz)
    translations.js faylida 100+ kalit so'z 3 tilda (uz/ru/en).
    useLanguage() hook orqali istalgan komponentda t('kalit') chaqiriladi.


─────────────────────────────────────────
1.2 BACKEND — Node.js + Express.js
─────────────────────────────────────────

Nima uchun Node.js + Express?
  JavaScript bilan ishlash — frontend va backend bir xil tilda.
  Express — eng yengil va moslashuvchan Node.js freymvorki.
  MVP uchun ideal: tez ishlab chiqish, kam konfiguratsiya.

Modullar:

  Express.js (server.js)
    REST API serveri. Barcha route'lar /api/ prefiksi bilan.
    Global error handler — barcha xatolarni ushlab JSON qaytaradi.

  bcryptjs
    Parollarni xavfsiz saqlash uchun hashing (bir tomonlama shifrlash).
    Foydalanuvchi parolni kiritsа, bcrypt.compare() bilan tekshiriladi.
    Hech qachon ochiq parol saqlanmaydi.

  jsonwebtoken (JWT)
    Autentifikatsiya uchun. Login qilganda server token yaratadi:
    { userId, role } ma'lumotlari + JWT_SECRET bilan imzolangan.
    Token 7 kun amal qiladi. Har bir so'rovda Authorization: Bearer
    headerida yuboriladi va middleware/auth.js tekshiradi.

  Multer
    Fayl yuklash uchun. Virtual tour video (.mp4, .mov, .webm)
    va preview rasmlari serverga yuklanadi.
    backend/uploads/ papkasida saqlanadi.

  Middleware tuzilmasi:
    protect  → JWT tokenni tekshiradi, req.user ni to'ldiradi
    owner    → faqat role='owner' yoki 'admin' o'ta oladi
    admin    → faqat role='admin' o'ta oladi


─────────────────────────────────────────
1.3 DATABASE — SQLite (better-sqlite3)
─────────────────────────────────────────

Nima uchun SQLite?
  MVP uchun mukammal tanlov:
  - Alohida server kerak emas (fayl asosida ishlaydi)
  - Zero configuration — npm install qilib ishlatsa bo'ladi
  - better-sqlite3 — sinxron API, PostgreSQL/MySQL ga o'tish oson
  - WAL mode — parallel o'qish tezroq

Jadvallar (12 ta):
  users              → foydalanuvchilar (id, name, email, password_hash, role)
  businesses         → bizneslar (id, name, category, lat, lng, status, view_count ...)
  services           → xizmatlar (narx, davomiylik, flash deal ma'lumotlari)
  bookings           → band qilishlar (sana, vaqt, narx, status)
  reviews            → sharhlar (1-5 yulduz, izoh)
  favorites          → sevimlilar
  notifications      → bildirishnomalar
  conversations      → chat suhbatlari
  messages           → chat xabarlari
  vr_tours           → VR tur ma'lumotlari (eski tizim)
  business_virtual_tours → Virtual ko'rish (yangi tizim, faol)
  promoted_deals     → Admin reklama aktsiyalari (yangi)

normalizeBusiness(), normalizeService() funksiyalari —
  DB row'larini frontend tushunadigan JSON formatga o'tkazadi.


─────────────────────────────────────────
1.4 API ARXITEKTURASI — REST
─────────────────────────────────────────

Asosiy endpoint'lar:

  /api/auth          → register, login, profil, sevimlilar
  /api/businesses    → CRUD bizneslar, sharhlar
  /api/services      → CRUD xizmatlar, flash deals
  /api/bookings      → band qilish, slot'lar, status o'zgartirish
  /api/admin         → moderatsiya, statistika, promoted deals
  /api/chat          → suhbatlar, xabarlar
  /api/ai-chat       → AI yordamchi (Groq yoki lokal fallback)
  /api/notifications → bildirishnomalar
  /api/business/:id/virtual-tours → Virtual ko'rish
  /api/vr-tours      → VR tur (eski tizim)
  /api/users         → admin foydalanuvchi boshqaruvi

HTTP metodlar to'g'ri ishlatilgan:
  GET    → ma'lumot olish
  POST   → yangi yaratish
  PUT    → to'liq yangilash
  PATCH  → qisman yangilash (status o'zgartirish)
  DELETE → o'chirish
